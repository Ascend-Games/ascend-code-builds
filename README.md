# Ascend Code builds

Installers and update files for **Ascend Code**, Ascend Games' build of [T3 Code](https://github.com/pingdotgg/t3code) for multi-vendor agent work on Unreal projects. Built files only, never source; the source is private at `Ascend-Games/ascend-code`.

## Install

Download the newest `Ascend-Code-<version>-x64.exe` from [Releases](../../releases/latest) and run it. It installs for your Windows user, beside any T3 Code install, and keeps its own settings and threads. After that the app updates itself from this repository's releases.

The installer is not code-signed, so Windows SmartScreen may warn on first run: choose **More info**, then **Run anyway**.
